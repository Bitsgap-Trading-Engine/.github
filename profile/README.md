## System Deployment Protocol

1. Launch your browser or desktop container and log into your Bitsgap workspace environment.
2. Navigate to **My Exchanges** and connect your preferred exchange accounts by generating and attaching read/trade API keys.
3. Configure administrative security protocols, ensuring API withdrawal permissions are explicitly disabled on exchange endpoints.
4. Access the **Bots** workspace, select an execution strategy (**GRID**, **DCA**, or **Combo Bot**), set asset pairs, and define upper/lower price limits.
5. Backtest your chosen strategy against historical market data feeds before launching live algorithmic order execution.
